# Пси / PSI (Ψ)

Универсальная CAD-система в стиле Claude (слоновая кость / графит, терракотовый акцент `#D97757`, serif-заголовки),
русский интерфейс, macOS 11+ Intel x64. C++20 · Qt 6 Widgets · CMake + Ninja.

**Этап 00–01 (Draft MVP):** 2D-черчение с точным вводом, слои, объектные привязки, размеры (ассоциативные),
штриховка, выноски, текст; листы с рамкой и основной надписью (ГОСТ 185×55), видовые экраны с масштабом;
точный векторный PDF (1 мм = 1 мм); импорт / экспорт DXF (AC1015, с определением единиц); собственный формат
`.psi` (ZIP + JSON, контроль целостности, миграции); автосохранение и восстановление; самопроверка `psi --selftest`.

## Сборка

```bash
cmake --preset release          # нужны Qt 6.4+ (Core Gui Widgets PrintSupport Svg Test), zlib, Ninja
cmake --build --preset release
ctest --preset release          # 12 наборов тестов, офскрин
build/apps/psi-desktop/psi --selftest
```

macOS-пакет (`.dmg`, macdeployqt, проверка минимальной версии macOS, самопроверка собранного бинаря):

```bash
QT_ROOT=~/Qt/6.7.3/macos packaging/macos/build_macos.sh
```

CI: `.github/workflows/psi-macos.yml` — сборка и тесты на каждый push, релиз по тегу `psi-v*` или
`workflow_dispatch` с `release_version`.

## Структура

| Каталог | Что внутри |
|---|---|
| `core/` | геометрия (`Point`, `Rect`, `Transform`, `Entity` и операции: смещение, обрезка, удлинение, скругление, фаска, размеры; `ops`: соединение, разрезание), единицы, атрибуты, документ (слои, листы, пространственный индекс), стек команд, проект (открытие / сохранение / автосохранение / недавние) |
| `modules/drawing/` | листы: форматы, масштабы, видовые экраны, основная надпись |
| `modules/draft/` | инструменты черчения (состояния, призраки, клавиатурный ввод), булевы операции (`boolean`), правка по значению (`edit`), привязки и магнит к сетке, парсер ввода, демо-сценарий |
| `io/native/` | формат `.psi` (ZIP на zlib, манифест с sha256, схема 1) |
| `io/dxf/` | DXF: запись и чтение |
| `io/pdf/` | PDF-экспорт листов с точным размером страницы |
| `rendering/` | рендерер (QPainter, косметические перья, штриховка, текст, листы) и `Viewport` (кеш, пакетная отрисовка, выделение, привязки) |
| `ui/` | тема (светлая / тёмная, акцент), иконки (рисуются кодом), встроенный редактор над видовым экраном |
| `apps/psi-desktop/` | главное окно, доки, страница «Листы», диалоги, начальный экран, самопроверка |
| `tests/` | unit / formats / printing / performance / integration (QTest) |
| `docs/` | архитектура, ADR, форматы |
| `design/figma/` | скрипты UI-кита и экранов для файла «Пси — UI» |
| `packaging/macos/` | скрипт сборки `.dmg`, Info.plist, проверка minos, иконка |

Подробнее: [docs/architecture.md](docs/architecture.md), [docs/formats/psi.md](docs/formats/psi.md),

## Работа в программе

- Инструменты (палитра слева: поиск, группы «Избранное» (8 недавних) / «Рисование» / «Текст и размеры» / «Правка» /
  «Объединение» / «Штриховка», компактный режим ▦): `L` линия, `P` полилиния, `R` прямоугольник, `C` окружность, `A` дуга,
  `E` эллипс, `S` сплайн, `T` текст, `⇧L` выноска, `D` размер (`⇧H` / `⇧V` / `⇧R` / `⇧D` / `⇧A`), `H` штриховка,
  `M` переместить, `⇧C` копировать, `⇧O` повернуть, `⇧M` зеркало, `⇧S` масштаб, `O` смещение, `⇧T` обрезать, `⇧E` удлинить,
  `F` скругление, `⇧F` фаска, `⇧Y` массив, `X` расчленить; **Объединение:** `J` соединить (линии / дуги / полилинии с общими
  концами → одна полилиния), `⇧U` объединить, `⇧B` вычесть, `⇧I` пересечение (булевы операции над замкнутыми контурами,
  `Shift` при втором щелчке — оставить исходные), `⇧X` разрезать в точке, `⇧K` разрезать объектом; `Enter` / правая
  кнопка — завершить шаг, `Esc` — отмена, `Shift` — орто.
- Магнит к круглым координатам: `F9` или кнопка «⌁ Сетка 1 мм» в строке состояния (меню — шаг 0.5 / 1 / 5 / 10 / 50 /
  100 мм или свой); курсор подтягивается к ближайшему кратному шагу в радиусе 8 px (объектная привязка важнее), в точке —
  квадратный маркер, в строке состояния — точные координаты. `Tab` в командной строке округляет введённое число.
- Двойной щелчок по объекту — встроенный редактор: размер (меняет измеряемую геометрию, например ширину прямоугольника),
  длина / угол линии, ширина × высота прямоугольника, радиус / диаметр окружности, текст; `Enter` — применить (отменяемо),
  `Esc` — отмена.
- Командная строка: `100,50` · `@40,10` · `@80<30` · `250` (длина вдоль курсора) · `80 cm` · `2'` · псевдонимы `l`, `c`, `r`, `m`…
- Рабочие области «Эскиз», «Модель», «Сборка», «Интерьер», «Чертёж 3D» отключены — этапы 02–06.
