# ADR-002 · Контейнер `.psi`: ZIP + JSON, манифест с sha256, миграции

**Статус:** принято (этап 00).

## Контекст

Собственный формат должен быть долгоживущим, расширяемым модулями будущих этапов, устойчивым к повреждениям и удобным
для диффов и отладки.

## Решение

- ZIP (deflate через zlib, собственный минимальный писатель/читатель в `io/native/zip.cpp`, без сторонних ZIP-библиотек).
- Части — JSON: `manifest.json` (версия схемы, sha256 каждой части), `project/*`, `drawings/main.json`, `sheets/sheets.json`.
- Неизвестные части сохраняются при пересохранении («foreign parts») — модули будущих этапов не ломают старые сборки.
- `kSchemaVersion`; файлы более новой схемы отклоняются с понятным сообщением, более старые проходят миграцию.
- Лимиты распаковки против zip-бомб, проверка CRC и sha256.

## Отвергнуто

- SQLite: не диффуется, тяжелее расширять модулями, нужен ещё один зависимый компонент.
- Один большой JSON: нет места под бинарные вложения (текстуры, превью) и отдельной проверки целостности частей.
- Бинарная сериализация Qt (`QDataStream`): непрозрачна и привязана к версиям Qt.

## Последствия

Файл можно открыть архиватором и прочитать; интеграция с git-репозиториями проектов возможна; размер файла с 50 000
линий — единицы мегабайт, запись/чтение — доли секунды.
