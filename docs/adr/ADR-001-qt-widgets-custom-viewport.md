# ADR-001 · Qt 6 Widgets и собственный Viewport вместо QGraphicsView / QML

**Статус:** принято (этап 00).

## Контекст

Нужен отзывчивый 2D-холст на десятки тысяч объектов, макOS 11 Intel, минимальный размер пакета, стиль Claude.

## Решение

- Qt 6 Widgets (без QML, без QtQuick, без QtNetwork). QSS-тема из `ui/theme.cpp`.
- Собственный `Viewport : QWidget`: статический слой документа кешируется в `QPixmap` и перерисовывается только при
  изменении документа или вида; оверлей (выделение, призрак инструмента, привязки) рисуется поверх каждый кадр.
  Линии группируются по перу и рисуются одним `drawLines`, прочие объекты — через `QPainterPath`.
- Поиск объектов — `SpatialIndex` (равномерная сетка), а не обход всех объектов.

## Отвергнуто

- `QGraphicsView`: накладные расходы на `QGraphicsItem` для каждого объекта, сложное управление стилями и
  привязками, медленнее при массовом обновлении.
- QML/QtQuick: тяжелее пакет, стиль сложнее держать единым с виджетами, нет выигрыша для 2D-CAD.

## Последствия

Больше своего кода в `rendering/`, зато полный контроль над производительностью и внешним видом; 50 000 линий
рендерятся за сотни миллисекунд, hover/выделение не перерисовывают документ.
