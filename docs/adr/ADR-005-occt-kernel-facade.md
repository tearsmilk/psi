# ADR-005 · Open CASCADE за фасадом `psi::md::Kernel`, дерево построения и программный 3D-вид

**Статус:** принято (этап 02 «Модель»).

## Контекст

ТЗ требует параметрическое 3D (эскиз → выдавливание / вращение, отверстия, скругления, массивы, булевы операции),
импорт / экспорт STEP и STL, массовые характеристики и 3D-вид с выбором граней / рёбер / вершин — на macOS 11+ Intel,
с офскрин-тестами в CI. Единственное зрелое открытое B-Rep-ядро — Open CASCADE (OCCT): ~150 заголовочных пакетов,
собственная система типов (`Handle`, `TopoDS_*`), медленная компиляция и исключения `Standard_Failure`.

## Решение

- **Фасад.** Вся работа с OCCT — в библиотеке `psi_model` (`modules/model`, `io/step`, `io/stl`). Наружу выходят только
  типы `psi::md`: `Vec3`, `Plane`, `Profile`, `Shape` (pimpl над `TopoDS_Shape`), `Mesh`, `Result` (тело либо
  русское сообщение об ошибке) и статические операции `Kernel::*`. Заголовки OCCT подключают только `kernel.cpp`,
  `step.cpp`, `stl.cpp` через внутренний `kernel_occt.h`. Исключения ядра перехватываются внутри и превращаются в `Result`.
- **Опция сборки.** `PSI_WITH_OCCT` включается автоматически, если `find_package(OpenCASCADE)` нашёл ядро; без него
  программа собирается целиком, а кнопка «Модель» отключена с подсказкой «Собрано без OCCT». Линкуются только нужные
  тулкиты (TKernel … TKFillet, TKOffset, TKMesh, STEP / STL), имена 7.6 (`TKSTEP`, `TKSTL`) и 7.8+ (`TKDESTEP`, `TKDESTL`)
  выбираются по наличию целей.
- **Дерево построения** (`Part`) — упорядоченный список `Feature{type, params: QJsonObject}`. Параметры — обычный JSON с
  документированными ключами (`part.h`): так одна схема обслуживает диалоги, панель свойств, файл и тесты. Перестроение
  идёт с первой изменённой операции по кэшу состояний; неудачная операция помечается ошибкой «имя: причина», а состояние
  тел остаётся последним удачным. Массивы и зеркало повторяют *тело-инструмент* исходной операции (призма, цилиндр
  отверстия) и применяют его тем же режимом — без повторного решения эскиза.
- **Хранение.** Деталь — чужая часть `.psi` `models/<id>.json` (без изменения схемы контейнера), рядом кэш
  `assets/model_<id>.brep` (`BRepTools::Write`) для просмотра без перестроения.
- **3D-вид без OpenGL.** `View3D` — программный растеризатор (z-буфер + буфер идентификаторов грань/тело) в `QImage`,
  рёбра и сетка — сглаженные линии QPainter с проверкой глубины. Выбор граней — по буферу идентификаторов, рёбер и
  вершин — по расстоянию на экране с проверкой видимости.

## Отвергнуто

- **QOpenGLWidget (3.3 core).** На macOS 11 OpenGL объявлен устаревшим, в CI (`QT_QPA_PLATFORM=offscreen`) контекст
  ненадёжен, а картинка зависит от драйвера. Кадр плиты 1280×800 программно рисуется за ~20 мс — для деталей из
  десятков операций этого достаточно; при необходимости растеризатор заменяется на GPU-бэкенд за тем же интерфейсом.
- **Прямое использование `TopoDS_Shape` в UI.** Утечка заголовков OCCT в `psi_ui` удвоила бы время компиляции и
  привязала бы весь интерфейс к версии ядра.
- **Хранение тел в документе `Document`.** Операции модели — не 2D-объекты; снимки JSON (`SnapshotStack`) дешевле и
  проще команд с копиями тел.

## Последствия

Любая новая 3D-операция — это ключи в `part.h`, ветка в `Part::applyFeature`, строка схемы в `model_page.cpp` и тест в
`test_model`. Сборка с OCCT в CI идёт через vcpkg (оверлей-триплет `x64-osx-11`) с кэшем бинарников, см. `psi-macos.yml`.
