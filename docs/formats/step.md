# STEP (ISO 10303-21, AP214)

Экспорт и импорт тел рабочего пространства «Модель» через `STEPControl_Writer` / `STEPControl_Reader` (`io/step`).

| | Экспорт | Импорт |
|---|---|---|
| Единицы | мм (`write.step.unit = MM`) | любые из файла → пересчёт в мм (`xstep.cascade.unit = MM`) |
| Тела | каждое тело детали → `PRODUCT` с именем тела | каждый корень → тело «Тело N» (операция «Импорт», участвует в булевых) |
| Поверхности без объёма | записываются | импортируются с предупреждением (булевы недоступны) |
| Тело-сетка (STL) | пропускается с предупреждением — сохраняйте в STL | — |
| Имена продуктов | записываются | не читаются (без XDE) — указано в отчёте |
| Цвета / слои / сборки | нет | нет |

Отчёт (`StepReport::summary()`) по образцу DXF: корней / тел / граней, единицы, пропущенное, предупреждения, отмена.
Проверка: `test_model::stepRoundTrip` — объём плиты с отверстием совпадает после записи и чтения с точностью 1e-6.
