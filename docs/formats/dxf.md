# DXF

ASCII DXF в стиле AutoCAD 2000 (`$ACADVER = AC1015`). Реализация — `io/dxf/dxf.{h,cpp}`.

## Экспорт

- HEADER: `$ACADVER`, `$INSUNITS` (4 = мм), `$EXTMIN` / `$EXTMAX`.
- TABLES: `LTYPE` (CONTINUOUS, DASHED, DOT, DASHDOT), `LAYER` (имя, цвет как true color + ближайший ACI, тип линии,
  толщина в сотых мм, флаги заморозки/блокировки).
- ENTITIES: `LINE`, `LWPOLYLINE` (с bulge и замыканием), `CIRCLE`, `ARC` (градусы), `ELLIPSE`, `SPLINE` (по точкам
  аппроксимации), `HATCH` (SOLID / штриховые паттерны с углом и шагом), `TEXT`. Выноски и размеры экспортируются как
  геометрия (`LINE`/`LWPOLYLINE`/`ARC`) + `TEXT` — без зависимости от стилей размеров.
- Текст — UTF-8 (как пишут современные CAD); кириллица сохраняется.

## Импорт

- Поддержаны: `LINE`, `LWPOLYLINE`, `POLYLINE`/`VERTEX`/`SEQEND`, `CIRCLE`, `ARC`, `ELLIPSE`, `SPLINE` (по контрольным
  или fit-точкам), `TEXT`, `MTEXT` (`\P` → перенос, форматирование снимается), `HATCH` (границы из рёбер).
- Единицы: `$INSUNITS` → перевод в мм. Если не задан — `DxfReport::unitGuessed = true`, приложение спрашивает
  пользователя, по умолчанию `DxfOptions::fallbackUnit`.
- Слои сливаются с существующими по имени (`mergeLayers`), цвета ACI переводятся в RGB.
- Неподдержанные типы (`INSERT`, `3DFACE`, `DIMENSION`, `SOLID` и т. п.) пропускаются и перечисляются в отчёте;
  бинарный DXF и DWG не поддерживаются.
- Разбор потоковый, с колбэком отмены; результат применяется одной командой «Импорт DXF» (можно отменить).

## Ограничения этапа 01

Блоки (`INSERT`/`BLOCK`) не разворачиваются, размеры (`DIMENSION`) не читаются как ассоциативные, стили текста и
`MTEXT`-форматирование игнорируются.
