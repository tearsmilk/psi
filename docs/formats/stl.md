# STL (двоичный и текстовый)

`io/stl` на `RWStl`. STL безразмерен — Пси считает значения миллиметрами.

| | Экспорт | Импорт |
|---|---|---|
| Формат | двоичный (по умолчанию) или текстовый | определяется автоматически по заголовку |
| Тесселяция | `BRepMesh_IncrementalMesh`, линейное отклонение `deflection` (0,1 мм по умолчанию), угловое 0,3 рад | — |
| Результат | один файл на деталь: все тела подряд | **тело-сетка**: операция «Тело-сетка» в дереве, показ / габариты / повторный экспорт; без параметров, булевых операций, скруглений и STEP |
| Отчёт | треугольников, вершин, формат | то же + предупреждение о непараметричности |

Сетка хранится в параметрах операции (`mesh`, base64: `uint32 n, uint32 t, float·3n, uint32·3t`), поэтому `.psi`
с импортом STL самодостаточен. Проверка: `test_model::stlExportImport` (оба формата, число треугольников, габариты).
