# Figma: Пси — UI

Файл «Пси — UI» в команде **Lotus** (создаётся при первом запуске скриптов через `use_figma`).

> **Правило:** UI-кит и *все* экраны Пси живут в Figma. Любой новый экран, диалог или компонент добавляется
> в эти скрипты в том же изменении, что и код, и выкладывается в Figma.

1. `01_ui_kit.js` — страница **UI Kit**: токены (коллекции «Psi — Light» / «Psi — Dark», зеркало
   `ui/theme.cpp`), типографика (serif-заголовки, Inter, моноширинная командная строка), иконка Ψ, компоненты:
   кнопки (акцент / обычная / недоступная), панель рабочих областей, док «Инструменты» — палитра с поиском, сворачиваемыми
   группами (Избранное / Рисование / Текст и размеры / Правка / Объединение / Штриховка), кнопками 36 px с подписями и
   компактным режимом (только иконки),
   док «Слои», док «Свойства» (стиль, геометрия, атрибуты), «Дерево документа», командная строка с подсказкой,
   строка состояния с переключателем «⌁ Сетка 1 мм» (магнит к круглым координатам), встроенные редакторы
   (размер, длина / угол, ширина × высота, радиус / диаметр, текст), маркер магнита (закрашенный квадрат + координаты),
   образец холста (сетка, выделение с ручками, маркер привязки, перекрестие, размер), превью листа с
   основной надписью, карточка начального экрана, диалог, тост, прогресс импорта.
2. `02_screens.js` — страница **Screens**:

| Экран | Темы | В приложении |
|---|---|---|
| Начальный экран — логотип Ψ, «Новый проект / Открыть / Импорт DXF / Демонстрация», недавние | Light, Dark | при запуске, `⌘0` |
| Черчение — панель рабочих областей, доки Инструменты / Дерево слева, холст с сеткой и планом комнаты, командная строка, доки Свойства / Слои справа, строка состояния | Light, Dark | «Черчение», `⌘1` |
| Черчение — объект выбран: ручки, панель свойств с геометрией и атрибутами | Light | щелчок по объекту |
| Черчение — инструмент «Линия»: призрак, полярное отслеживание, маркер привязки, ввод `@2600<90` | Light | `L` |
| Черчение — магнит к сетке: квадратный маркер в круглой точке, подпись «Сетка · 3500, 2600», кнопка «⌁ Сетка 10 мм» | Light | `F9`, строка состояния |
| Черчение — правка по двойному щелчку: встроенный редактор над размером (`800 → 1000`) | Light | двойной щелчок по объекту |
| Черчение — палитра: поиск («раз» → размеры и разрезание) | Light | поле поиска в доке «Инструменты» |

| Листы — список листов, превью A3 с рамкой / основной надписью / видом, форма листа, основная надпись, виды, PDF | Light, Dark | «Листы», `⌘2` |
| Диалоги — Параметры документа (единицы, сетка, шаг привязки, магнит, привязки), Настройки (тема, акцент, автосохранение, горячие клавиши), Слой, отчёт импорта DXF, предупреждение экспорта PDF | Light | Правка → …, Файл → … |

Запуск: в `use_figma` с `fileKey` файла «Пси — UI» выполнить сначала `01_ui_kit.js`, затем `02_screens.js`.
Скрипты перестраивают свои страницы целиком (идемпотентны). Starter-план Figma ограничивает число MCP-вызовов
в месяц — при ошибке лимита повторить позже.

Статус: скрипты написаны вместе с кодом этапа 00–01, **в Figma ещё не выложены** (плагин Figma требует повторной
авторизации в текущей сессии).
