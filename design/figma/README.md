# Figma: Пси — UI

Файл «Пси — UI» в команде **Lotus** (создаётся при первом запуске скриптов через `use_figma`).

> **Правило:** UI-кит и *все* экраны Пси живут в Figma. Любой новый экран, диалог или компонент добавляется
> в эти скрипты в том же изменении, что и код, и выкладывается в Figma.

1. `01_ui_kit.js` — страница **UI Kit**: токены (коллекции «Psi — Light» / «Psi — Dark», зеркало
   `ui/theme.cpp`), типографика (serif-заголовки, Inter, моноширинная командная строка), иконка Ψ, компоненты:
   кнопки (акцент / обычная / недоступная), панель рабочих областей, док «Инструменты» (Создать / Аннотации / Изменить),
   док «Слои», док «Свойства» (стиль, геометрия, атрибуты), «Дерево документа», командная строка с подсказкой,
   строка состояния, образец холста (сетка, выделение с ручками, маркер привязки, перекрестие, размер), превью листа с
   основной надписью, карточка начального экрана, диалог, тост, прогресс импорта.
2. `02_screens.js` — страница **Screens**:

Запуск: в `use_figma` с `fileKey` файла «Пси — UI» выполнить сначала `01_ui_kit.js`, затем `02_screens.js`.
Скрипты перестраивают свои страницы целиком (идемпотентны). Starter-план Figma ограничивает число MCP-вызовов
в месяц — при ошибке лимита повторить позже.

Статус: скрипты написаны вместе с кодом этапов 00–01, 02 «Эскиз» и 05 «Интерьер», **в Figma ещё не выложены** (плагин Figma требует повторной
авторизации в текущей сессии).
