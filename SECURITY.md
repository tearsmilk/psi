# Безопасность

Пси работает полностью локально: нет сетевых запросов, телеметрии и учётных записей. Единственные внешние данные —
файлы, которые открывает пользователь.

## Что сделано

- **`.psi` (ZIP):** лимиты распаковки (часть ≤ 64 МБ, суммарно ≤ 512 МБ, ≤ 10 000 записей) против zip-бомб, проверка CRC
  и sha256 каждой части по манифесту, отказ от неизвестных будущих версий схемы, пути записей не выходят за пределы
  архива (не используются как пути на диске).
- **DXF:** потоковый разбор без рекурсии, неизвестные сущности пропускаются и попадают в отчёт, числа проверяются на
  конечность, импорт можно отменить.
- **PDF:** запись во временный файл рядом с целевым и атомарное переименование.
- **Автосохранение:** `<файл>.autosave.psi` рядом с проектом (или в каталоге данных приложения для несохранённого проекта),
  резервная копия `.bak` при перезаписи.
- Секретов, ключей и сетевого кода в репозитории нет.

сообщения; не открывайте публичный issue до исправления. Ответ — в течение 7 дней.
